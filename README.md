# 🎯 FocaAi

**FocaAi** é um aplicativo mobile desenvolvido com o objetivo de ajudar estudantes a manter o foco, organizar sua rotina de estudos e acompanhar seu progresso utilizando a técnica Pomodoro.

## 📖 Sobre o projeto

O FocaAi surgiu da necessidade de ajudar estudantes que enfrentam dificuldades para manter a concentração durante os estudos, organizar o tempo e estabelecer pausas adequadas.

A proposta é oferecer uma ferramenta simples e intuitiva que auxilie na organização dos estudos, no gerenciamento do tempo e no acompanhamento das sessões realizadas.
